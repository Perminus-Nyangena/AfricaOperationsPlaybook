# Africa Operations Playbook
 
Practical templates for running manufacturing, supply chain and distribution across African markets, from Technophiles Advisory.
 
## In this repository
 
* supplier-scorecard.md: rate and review suppliers
* inventory-control.md: stock counts, reorder points and variance checks
* sales-and-operations-rhythm.md: a monthly cycle linking demand, production and cash
* distributor-performance-review.md: a simple quarterly review
* finance-committee-pack.md: what a treasury and finance committee should see each month
 
## Who it is for
 
Operations leads, country managers and founders building a first supply chain.
